# Remix Kit: A Set of Launch Graphics

**From the AI Influenceher build log.** Make a matching set of announcement graphics for a launch, sized for each platform, in your colors and fonts, with text you can still edit.

| | |
|---|---|
| **Time** | About 1 to 2 hours |
| **Skill level** | Beginner friendly. No coding. |
| **You end up with** | A set of 6 to 10 graphics sized for Instagram, LinkedIn and X, ready to post |

---

## How to use this file

1. Download this file.
2. Open a new chat at [claude.ai](https://claude.ai) and attach it.
3. Type: **"Let's start this remix kit."**
4. Claude will walk you through it one step at a time. Answer its questions, then keep going.

You don't need to read the rest unless you're curious. Claude will handle it.

## Step 1: Who you are

Claude asks these first, so the result fits the person using it. Anyone can use this kit: nonprofits, small businesses, event organizers, creators and agencies.

1. **What do you do, and who is this for?** (For example: We're launching a new page, we got press, we're announcing a new city)
2. **What are you announcing?**
3. **Which platforms?**
4. **What's the mix?** Brand-led posts, quote cards, news-style posts, a call to action
5. **How comfortable are you with tech?** New to this, I get by, or very comfortable

When you're done, you'll have:

- **A matching set** of graphics with a headline, quote cards and a call to action
- **Sizes for each platform**
