# Remix Kit: A Watch Guide for a Conference

**From the AI Influenceher build log.** Turn a big conference's talk recordings into one row per session with takeaways and a Watch, Skim or Skip verdict, plus a top ten and tool list.

| | |
|---|---|
| **Time** | About 1 hour |
| **Skill level** | Beginner friendly. No coding. |
| **You end up with** | A watch guide with a top ten, one row per talk and a list of tools speakers mentioned |

---

## How to use this file

1. Download this file.
2. Open a new chat at [claude.ai](https://claude.ai) and attach it.
3. Type: **"Let's start this remix kit."**
4. Claude will walk you through it one step at a time. Answer its questions, then keep going.

You don't need to read the rest unless you're curious. Claude will handle it.

## Step 4: What this builds

When you're done, you'll have:

- **A top ten** so you know where to start
- **One row per talk** with takeaways, tools named and a verdict
- **A tools list** of everything speakers mentioned
- **Notes from the actual recordings**, not from memory

**Why it helps:** Fifty talks is too many to watch. A guide picks the best for you.
