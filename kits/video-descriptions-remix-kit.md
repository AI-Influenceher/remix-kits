**From the AI Influenceher build log.** Give old videos clear titles and descriptions in one consistent format, with chapters for long talks and flags for anything unconfirmed.

## Step 1: Who you are

Claude asks these first, so the result fits the person using it. Anyone can use this kit: nonprofits, event organizers, educators, podcasters and creators with big back catalogs.

1. **What do you do, and who is this for?** (For example: We post event recordings, I have years of old videos, I run a course channel)
2. **How many videos need work?**
3. **What kind of videos are they?** Talks, interviews, tutorials, events
4. **Do you have transcripts?** YouTube auto captions, a tool like Otter, or none
5. **How comfortable are you with tech?** New to this, I get by, or very comfortable

## Step 2: Your tech stack

A "tech stack" is just the list of tools a project uses.

| Tool | Needed? | What it's for |
|---|---|---|
| [Claude](https://claude.ai) | Yes | Writes titles and descriptions as a saved skill |

| [Otter](https://otter.ai) or YouTube captions | Optional | Transcripts let Claude add chapters and check facts |

**What's a skill?** A saved set of instructions Claude follows every time, so every description comes out in the same format.

---

## Step 4: What this builds

When you're done, you'll have:

- A **consistent format** for every description, so the channel reads as one library
- **Strong first two lines** that say what the viewer will learn, since that's all that shows before "more"
- **Chapters** with timestamps for long talks, when a transcript is available
- **Clearer titles** that lead with the topic, and **flags** for any fact Claude couldn't confirm

**Why it helps:** Old videos with file-name titles are hard to find and easy to skip.

---

## Step 5: The build, step by step

### 5.1 Design the format
Claude drafts a 5 to 7 part description template. Approve it.

### 5.2 Share a test batch
Give Claude 3 videos and their transcripts.

### 5.3 Review the drafts
Check names, dates and facts. Claude flags anything unsure.

### 5.4 Save it as a skill
Claude shows a card to save it.

### 5.5 Run the rest in batches
Do 10 at a time and paste them into YouTube Studio.

## Make it even better

- Add **matching thumbnails** with a template.

- Write a **short post** for each video to reshare it.

## If something goes wrong

- **A speaker's name is wrong:** Give Claude a list of correct names and spellings.
- **No chapters:** Chapters need a transcript with timestamps.
