## Step 4: What this builds

When you're done, you'll have:

- **Events read straight from Google Calendar**
- **List and month views**
- **Add to my calendar** buttons for each event
- **A subscribe link** so people get every new date

**Why it helps:** If the website needs editing every time an event changes, it falls behind.
