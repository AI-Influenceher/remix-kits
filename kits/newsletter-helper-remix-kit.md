## Step 2: Your tech stack

A "tech stack" is just the list of tools a project uses.

| Tool | Needed? | What it's for |
|---|---|---|
| [Claude](https://claude.ai) | Yes | Reads links, files ideas and drafts issues as a skill |

| [Substack](https://substack.com), Kit or Mailchimp | Optional | Where you paste the final draft and send |

**What's a skill?** A skill is a saved set of instructions Claude follows every time you ask for that kind of task. You set it up once, then just say "add this to the newsletter."

---

## Step 4: What this builds

When you're done, you'll have:

- A way to **log ideas from any chat**: paste a link, name a section, and Claude writes a short entry with the main idea and an angle
- A **running ideas doc**, organized by section, newest first
- **Draft issues** that sound like your past issues, with three subject line options
- A **no-guessing rule**: missing facts get a question, never a made-up answer

**Why it helps:** Good links show up all day in different places and get lost before it's time to write.

---

## Step 5: The build, step by step

### 5.1 Name your sections
Pick 2 to 4 sections. Claude can suggest a simple set if you don't have one.

### 5.2 Teach it your voice
Share past issues. Claude writes a short voice description you approve.

### 5.3 Set up the ideas doc
Claude creates a doc with a heading for each section.

### 5.4 Write the rules
Read the link before writing, file under the right section, use a link-only note when a site blocks reading, never invent facts.

### 5.5 Save it as a skill
Claude shows you a card to save it. Now you can log ideas from any chat.

### 5.6 Draft your first issue
Say "draft this week's issue." Claude picks one idea per section and writes the draft.

## Make it even better

- Set a **scheduled task** that drafts the issue the night before send day.
- Add a **"used" mark** so ideas don't repeat.
- Ask for a **social post** version of each issue.

## If something goes wrong

- **It summed up a post it couldn't open:** Some social sites block reading. Paste the post text in, or let it save a link-only note.
- **It doesn't sound like me:** Share another past issue and ask Claude to tighten the voice notes.
