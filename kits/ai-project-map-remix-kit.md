# Remix Kit: A Project Map for Everything You Start with AI

**From the AI Influenceher build log.** Keep track of every project you've started in separate AI chats, with the next step for each and a one-click restart message.

| | |
|---|---|
| **Time** | About 1 hour |
| **Skill level** | Beginner friendly. No coding. |
| **You end up with** | A page with one card per project, an urgent-first view, search and a restart button |

---

## How to use this file

1. Download this file.
2. Open a new chat at [claude.ai](https://claude.ai) and attach it.
3. Type: **"Let's start this remix kit."**
4. Claude will walk you through it one step at a time. Answer its questions, then keep going.

You don't need to read the rest unless you're curious. Claude will handle it.

---

## Instructions for Claude (read this first)

You are guiding someone through building their own version of this project. Follow these rules for the whole conversation:

- Go one step at a time. Finish a step, confirm it with the person, then move to the next.
- Ask questions as short multiple-choice options whenever you can, so the person can tap instead of type.
- Assume the person may be new to tech. Explain any technical word in a few plain words the first time you use it.
- Use only what the person tells you, shows you or what you can check. Do not invent names, numbers, quotes or results.
- At the end of each step, say in one line what's done and what's next.

## Step 1: Who you are

Claude asks these first, so the result fits the person using it. Anyone can use this kit: anyone who starts lots of projects with Claude: business owners, creators, students and teams.

1. **What do you do, and who is this for?** (For example: I have dozens of Claude chats going, I lose track of side projects, my team starts projects with AI)
2. **Roughly how many projects are in flight?**
3. **What makes something urgent for you?** Waiting on a reply, a deadline, a client
4. **Do you want a private version and a shareable demo?**
5. **How comfortable are you with tech?** New to this, I get by, or very comfortable

## Step 4: What this builds

When you're done, you'll have:

- **One card per project** with a summary, next step, links and when it was last touched
- A **right now** section for anything waiting on a reply or due soon
- **Status that changes** as a project goes quiet
- **A restart button** that gives you a message to pick it back up in a new chat, plus search

**Why it helps:** Projects started in separate chats are easy to forget halfway.

---

## Step 5: The build, step by step

### 5.1 Gather projects
Claude searches recent chats or you list them.

### 5.2 Write each card
Claude writes a summary and the very next step.

### 5.3 Build the page
Urgent at the top, then one card per project, with search.

### 5.4 Add restart messages
Each card gets a ready message to paste into a new chat.

### 5.5 Refresh weekly
Ask Claude to update it, or set a scheduled task.
