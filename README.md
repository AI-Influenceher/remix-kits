# AI Influenceher Remix Kits

Step-by-step guides for building your own version of every project in the AI Influenceher build log, with Claude.

## How to use a kit

1. Pick a kit below and download it (or copy its text).
2. Open a new chat at [claude.ai](https://claude.ai) and attach or paste it.
3. Type: **"Let's start this remix kit."**
4. Claude asks who you are, what tools you use and what content you have, then walks you through the build one step at a time.

Every kit has the same parts: who you are, your tech stack, the content you'll need, what it builds, the steps, ways to make it better and fixes for common problems.
